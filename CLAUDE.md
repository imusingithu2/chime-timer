# Chime Timer - project rules
- Full specification: SPEC.md. Re-read the relevant section before each phase.
- Work in the phases at the end of SPEC.md, one at a time. After each phase: run tests, git commit, report, then STOP and wait for me.
- Report to me in simple Vietnamese (I am a complete beginner). Code, comments, file names and commit messages stay in English.
- Never ask me technical questions: choose a sensible default and tell me what you chose.
- Do NOT install Playwright or any browser-testing tool. Skip SPEC sections 11.3 and 11.4. The rest of section 11 still applies.
- Vanilla HTML/CSS/JS only. No frameworks, no npm runtime dependencies, no CDN. All URLs relative.
- Keep every source file under ~300 lines; make small targeted edits.
- Verify by running code. If a command fails, read the error, fix, retry.
- Do not run git push or any gh command. I deploy by myself.
- This machine has no Python. Use Node.js (tools/*.cjs, built-in modules only, no npm packages) for every tool script, including generating the PNG icons in Phase 5 (write a small PNG encoder using the built-in zlib module). Treat every mention of generate_sounds.py or generate_icons.py in SPEC.md as the .cjs equivalent.
